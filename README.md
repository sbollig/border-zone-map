# 100-Mile Border Zone map

A single-page map of the area within 100 air miles of any U.S. external boundary, where federal immigration officers claim expanded warrantless search authority (8 U.S.C. § 1357(a)(3); 8 CFR 287.1), with the contested Great Lakes reading drawn separately and 2024 Census population by distance band.

Static HTML. No server code, no cookies, no analytics. Open `index.html` or visit the published page.

**Not legal advice.** Sources, methods, and accuracy notes are in the page's "About the data" section.
